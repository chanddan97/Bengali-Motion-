# Product Requirements Document — BanglaMotion Mobile Studio

## 1. Product vision
Build an original, Bengali-first Android application for creating scene-based motion-graphics videos from scripts, voice/audio and SRT subtitles. The owner must be able to use the core app personally on an Android phone without a compulsory paid account.

## 2. Primary journey
Projects → Script → Voice/Audio → SRT → Format & Language → Template → Auto Match → Scene Editor → Preview → Watermark → Export MP4.

## 3. P0 — core features that must work
- Create, rename, duplicate, archive and delete local projects.
- Bengali and English script editor.
- Import audio from Android file picker; record audio only after permission is requested.
- Import, parse, edit, validate and export `.srt`.
- Create subtitles manually without AI.
- Split scenes from SRT cues and manually adjust scene boundaries.
- Aspect ratios 9:16, 1:1, 4:5 and 16:9.
- Language settings: বাংলা, English, বাংলা + English.
- Template gallery with real previews, not placeholder buttons.
- Scene timeline, text layers, background images/video, shapes and supported motion presets.
- Local preview and actual MP4 export using a tested rendering path.
- User watermark and optional developer watermark controls.
- Project backup/restore and clear storage warnings.

## 4. P1 — optional AI features
- Script rewrite, title/hook and scene-plan suggestions.
- Audio-to-SRT only when an explicitly configured model/provider supports the input and output required.
- AI scene visual descriptions and template recommendations.
- Optional image generation with provider/quota disclosure.
- All AI-generated JSON must pass schema validation before it can affect the project.

## 5. P2 — advanced
- Talking presenter/avatar and lip-sync only with explicit consent and a real provider.
- Advanced keyframes, masks and multilayer animation.
- Cloud sync, sharing and team features.

## 7. Watermark requirements
- User watermark: optional text or imported transparent PNG/WebP image; adjustable size, opacity, position, margins and time range.
- Developer watermark: optional app identity text/icon, off by default, separately configurable.
- Export screen shows both toggles and a preview.
- If both are enabled, show both in preview and export; prevent overlap with a warning and a reposition action.
- Never force a watermark or lock export behind a watermark payment.
- Persist settings per project; offer a global default.
- Watermark is composited into the final render, not merely drawn over the preview UI.

## 8. SRT requirements
- Import UTF-8 `.srt`; preserve Bengali Unicode.
- Parse cue index, start time, end time and multiline subtitle text.
- Validate timestamps, ordering, empty cues and malformed blocks.
- Edit cue text and timing; split/merge cues; shift all cues by an offset.
- Preview cue timing against audio/video.
- Export valid UTF-8 SRT.
- Manual subtitle authoring must work offline.
- Auto-transcription is optional and provider-backed, never represented as free/unlimited by default.

## 9. Export requirements
- MP4 output; target H.264 video + AAC audio when supported by device encoder.
- 720p and 1080p options, 30 fps default.
- Maintain selected aspect ratio with fit/fill/crop controls.
- Show actual export progress only when measurable; cancel safely where supported.
- Preserve project after failure; allow retry.
- Verify resulting file can be opened by Android media player.

## 10. Acceptance criteria
1. Projects survive force-close and reopen.
2. Valid Bengali SRT imports and exports without corrupted characters.
3. Invalid SRT gives useful line/block errors.
4. At least the 10 observed preset labels appear with working original template implementations.
5. Proposed styles are visibly marked as additional/original.
6. User watermark can be enabled, disabled, repositioned and rendered into exported video.
7. Developer watermark is off by default and can be enabled/disabled.
8. Watermark preview matches final export.
9. A local project can be edited without network.
10. AI options disclose network, quota and provider requirements.
11. Exported MP4 plays on a real target Android device.
12. No API key is embedded in the APK.
