# Template Library — Reference Labels and Original Design Specifications

## Reading this catalogue correctly
**Observed label** means the label was visible in sampled frames of the supplied primary mobile video. It does not prove the exact animation, colors, font, layer count or full template behavior. Those details below are proposed original designs so the app has a complete, implementable template library without copying proprietary art.

## C. Gallery filters
The reference UI appears to show category labels such as Text, 3D, News, Product and Brand. Use them as filters/tags. A category is not a separate template unless a real template definition exists.

## D. Template card requirements
Each card must show:
- Original thumbnail generated by the app team or properly licensed.
- Template name, category and short description.
- Aspect ratios supported.
- A 2–4 second lightweight preview or a still preview.
- “Observed label” or “Original addition” metadata in the catalogue/admin details.
- Favorite and recently used state stored locally.

## E. Design and implementation rules
- Never use the reference video's logo, proprietary thumbnails or exact artwork.
- Use Noto Sans Bengali or another licensed Bengali font with full glyph coverage.
- Ensure text-safe zones for 9:16, 1:1, 4:5 and 16:9.
- Respect user-selected text size and Android accessibility font settings.
- Use deterministic motion parameters so preview and export match.
- If a template requires a capability not implemented (e.g. true 3D), mark it as 2.5D/limited instead of pretending.
- Every template must have a schema-backed definition in `schemas/template-catalog.example.json`.
