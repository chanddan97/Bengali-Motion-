# Design System
- Original dark navy/near-black creator-studio aesthetic; warm yellow/orange primary action.
- Bengali typography: Noto Sans Bengali or another properly licensed full-glyph font.
- 48 dp touch targets; scalable text; no horizontal overflow.
- Rounded cards, compact step sections, strong contrast.
- Use original/licensed template thumbnails.
- Template previews must reflect actual implemented capabilities.
- Keep user and developer watermark controls in separate labelled sections.
