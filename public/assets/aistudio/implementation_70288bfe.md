# Implementation Plan

1. **Milestone 1:** Native Android shell, navigation, project CRUD, local persistence, language switch.
2. **Milestone 2:** Script editor and offline SRT parser/editor/exporter.
3. **Milestone 3:** Template JSON schema, gallery and original template renderers.
4. **Milestone 4:** Audio import, playback and recording.
5. **Milestone 5:** Scene editor and deterministic preview.
6. **Milestone 6:** User and optional developer watermark layers.
7. **Milestone 7:** Real MP4 export and device verification.
8. **Milestone 8:** Optional AI provider integration and secure backend.
9. **Release audit:** Permissions, storage, Bengali rendering, privacy, performance and APK testing.

Do not advance until the current milestone builds and its tests pass.
