# Audio Engine
- Import through Android document picker.
- Copy or reference files safely within app-managed storage; handle revoked URI permissions.
- Record only after explicit user tap and runtime permission.
- Show duration, playback, trim points and audio-to-SRT sync offset.
- Noise reduction must only be shown when a real local/native implementation is integrated.
- Manual SRT is always available.
- Auto transcription is optional, provider-backed and quota-dependent.
