# Mobile UI/UX
Bottom navigation: Projects, Templates, Settings.

Main project flow:
1. Script
2. Voice/Audio
3. SRT
4. Format/Language
5. Template
6. Auto Match
7. Scenes
8. Preview
9. Watermark
10. Export

SRT screen: Import, Paste, Create manually, cue list, cue editor, timing controls, preview and export.
Template screen: filters, preview cards, aspect-ratio compatibility, observed/proposed labels.
Watermark screen: separate User Watermark and Developer Watermark panels; independent toggles; preview; position and opacity controls.
Export screen: resolution, fps, aspect ratio, enabled watermark summary, progress and output location.
